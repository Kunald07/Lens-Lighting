Lens — Creative Lighting Landing Page 💡

A modern and visually engaging lighting product landing page created using HTML and CSS. The project focuses on creative layouts, typography, imagery, curved design elements, and a clean product-focused interface.

✨ Preview

Lens — Light of Your Life

The landing page presents a fictional lighting brand called Lens, with a visually rich hero section showcasing lighting products and a modern navigation interface.

🎨 Design

The design is inspired by modern product landing pages and focuses heavily on visual presentation.

The page uses:

Large typography
High-contrast colors
Layered sections
Circular and curved elements
Full-height hero sections
Product photography
Minimal navigation
Strong visual hierarchy


📸 Assets

The project currently uses externally hosted images from Unsplash and other image URLs included in the HTML.

For a production project, it is recommended to download and store required assets locally inside an assets folder.
